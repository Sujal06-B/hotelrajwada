YES RAJVADA HOTEL WEBSITE + PREMIUM ADMIN PANEL

1. Extract yes-rajvada-premium.zip.
2. Open index.html to view the hotel website.
3. Open admin.html to manage the website demo.

PREMIUM ADMIN FEATURES
- Dashboard overview and quick actions
- Hotel profile: name, tagline, phone, WhatsApp, address, timings, about and map URL
- Menu & pricing: add, edit, delete, category and availability
- Photo gallery: upload and delete photos
- Bookings & enquiries: manually add customer requests, search/filter, update status
- Offers & promotions: create, edit, activate/deactivate and delete offers
- Google Reviews: save the official Google review URL and preview/copy it
- Branch management: add, edit and delete branches
- JSON data backup: export, import and reset
- Public website reads hotel profile, WhatsApp number, review link and uploaded gallery photos from the same browser storage

IMPORTANT LIMITATIONS
This is a front-end demo. Data is saved only in the browser's Local Storage on the same device/browser. It does not include secure administrator login, cloud database, multi-device synchronization, actual online booking processing, email/SMS notifications, or live Google rating retrieval. Do not use it as a public production admin panel until a secure backend, authentication, database and cloud file storage are connected.

GOOGLE REVIEWS
Open Admin > Google Reviews and paste the official review link from the hotel's Google Business Profile. The website review button will use that URL. Google ratings/reviews cannot be fabricated or edited from this panel; customers submit reviews on Google.

BEFORE PUBLISHING
- Enter the correct phone and WhatsApp number.
- Enter the real address, opening hours and branch details.
- Add the official Google review URL.
- Replace stock/demo images with actual Yes Rajvada hotel photos.
- Deploy on a web host and add a secure backend before real customer data is collected.
